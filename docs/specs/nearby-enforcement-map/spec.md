# 내 위치·단속 위치 지도 표시

## 사용자 결과

[nearby-enforcement-history](../nearby-enforcement-history/spec.md)에서 조회한
결과를, 사용자는 목록뿐 아니라 지도 위에서 내 위치와 단속 이력 위치로 함께 확인할
수 있다.

## 승인된 범위

- 위치 조회가 성공하면, 기존 이력 목록 위에 지도를 추가로 표시한다. 목록은 그대로
  유지한다.
- 지도에는 내 현재 위치를 마커 1개로 표시한다.
- 반경 300m 이내 단속 이력이 있으면, 목록에 있는 것과 같은 이력을 지도 위에 각각
  마커로 표시한다.
- 지도는 Leaflet + react-leaflet(OpenStreetMap 타일)로 구현한다
  ([map-library](../../decisions/map-library.md) 결정 계약 참고).
- 지도는 확대·축소, 이동(pan)이 가능하다.

## 관찰 가능한 수용 기준

1. 위치 조회에 성공하면 지도가 목록 위에 나타나고, 내 위치가 마커로 표시된다.
2. 반경 300m 이내 이력이 있으면, 목록에 표시된 이력 수만큼 지도 위에도 마커가
   나타난다.
3. 반경 300m 이내 이력이 없으면, 지도에는 내 위치 마커만 표시되고 단속 마커는
   나타나지 않는다.
4. 지도 위에서 마우스 휠이나 확대·축소 버튼으로 확대·축소가 되고, 드래그로 이동이
   된다.
5. 위치 조회 중이거나 거부·미지원·오류 상태에서는 지도를 표시하지 않는다(좌표가
   없으므로 기존 상태 화면만 유지).

## 확정된 제약과 이유

- 지도 라이브러리는 Leaflet + react-leaflet(OpenStreetMap 타일)로 한정한다. API
  키 발급이나 외부 계정 승인 없이 바로 구현·검증할 수 있기 때문이다
  ([map-library](../../decisions/map-library.md)).
- 지도는 목록을 대체하지 않고 위에 추가한다. 기존 파일럿에서 검증한 목록 기반
  수용 기준([nearby-enforcement-history](../../specs/nearby-enforcement-history/spec.md))을
  그대로 유지하기 위함이다.
- 지도에 쓰는 좌표와 이력 데이터는 이미 `/api/nearby-enforcement`가 반환한 응답을
  그대로 재사용한다. 별도 API 호출이나 새 데이터 출처를 추가하지 않는다.

## 가정

- 마커를 클릭하면 해당 이력의 주소와 단속일시를 팝업으로 보여준다.
- 지도의 초기 확대 수준은 반경 300m 영역이 화면에 대략 들어오는 정도로 맞춘다.
- 이력이 많은 지역(예: 실제 확인된 서울시청 인근 1,052건)에서도 별도 클러스터링
  없이 개별 마커로 표시한다. 시각적 혼잡이나 렌더링 성능은 남은 위험으로 남긴다.

## 범위 밖 (이유)

- 마커 클러스터링·그룹화 — 이번 범위에서는 개별 마커로 충분한지 먼저 확인하고,
  필요성이 확인되면 다음 단계에서 다룬다.
- 카카오맵·네이버지도 등 상용 지도 서비스로 전환 — [map-library](../../decisions/map-library.md)에서
  이미 Leaflet + OpenStreetMap으로 확정했다.
- 경로 안내·길찾기 등 내비게이션 기능 — 이번 결과물은 위치 확인용이지 길찾기용이
  아니다.
- 사용자가 이동할 때 지도를 실시간으로 갱신하는 것 — 기존과 동일하게 1회 조회
  결과를 기준으로 한다.
- 목록과 지도 중 하나만 보여주는 뷰 전환(토글) — 이번 범위에서는 항상 함께
  표시한다.

## 유보된 결정

- 마커가 매우 많은 지역에서 클러스터링을 도입할지는 실제 사용 후 다시 판단한다.
- 목록/지도 뷰 전환(토글) 제공 여부는 다음 단계에서 정한다.

## 남은 위험

- 단속 이력이 많은 지역(1,000건 이상)에서 개별 마커를 모두 그리면 지도가
  시각적으로 혼잡하거나 렌더링이 느려질 수 있다. 실제 화면에서 확인이 필요하다.
- OpenStreetMap 공개 타일 서버는 무료 공개 서비스라 사용량 정책이 있다. 이번
  파일럿 규모에서는 문제가 없지만, 실제 서비스로 확장할 때는
  [map-library](../../decisions/map-library.md)의 재검토 조건을 참고해야 한다.

## 연결된 소스

- [nearby-enforcement-history spec](../nearby-enforcement-history/spec.md) — 이
  작업이 이어받는 목록 조회 기능의 수용 기준과 상태 정의.
- [map-library 결정 계약](../../decisions/map-library.md) — 지도 라이브러리 선택
  이유와 재검토 조건.
- [ui-composition 결정 계약](../../decisions/ui-composition.md) — 지도는 커스텀
  UI가 허용되는 표면이며, 주변 control·상태 표현은 기존 구성을 따른다.

이 스펙에 없는 세부 규칙은 위 소스가 갖고 있으므로, 구현 시 함께 참고한다.
