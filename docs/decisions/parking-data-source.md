# 단속 데이터 출처

## Decisions

- 지금 이 순간의 단속 여부를 알려주는 실시간 공개 API는 확보하지 않는다. 대신 서울시 불법주정차 단속 정보(OA-22190, 서울 열린데이터광장)의 과거 단속 이력 CSV를 데이터 출처로 삼는다.
- 실시간·예정 단속 안내는 후속 과제로 미룬다. PRODUCT.md의 "실시간 정보로 단속 위험을 미리 파악"이라는 약속은 이 결정이 반영된 뒤 다시 검토해야 한다.

## Boundaries

- 이 결정은 첫 사용자 결과물(현재 위치 근처 단속 이력 조회)과 이후 이어지는 이력 기반 기능에 적용된다.
- t-data.seoul.go.kr의 v2x 기반 실시간 API처럼 진짜 실시간성을 확보할 경로가 검증되면, 그 시점에 이 결정을 다시 연다.

## Why

서울 열린데이터광장에서 확인 가능한 관련 데이터셋을 조사한 결과, 실시간으로 접근 가능한 공개 API는 없었다.

- `OA-22190`(불법주정차 단속 정보): 단속일시·단속주소·위도·경도를 제공하지만 분기별 CSV 다운로드 방식이고, 갱신 주기도 "비정기(자료변경시)"라 이미 끝난 단속의 이력이다.
- `t-data.seoul.go.kr`(불법 주정차 위치 정보 서비스, data_id=10108): "실시간"으로 표기돼 있으나 C-ITS 카메라의 원시 검지 데이터이고, 별도 서울교통데이터포털 인증키가 필요하며 일반 개발자 접근 가능 여부가 명시돼 있지 않다.
- `OA-20471` 등 CCTV 위치정보: 상시 단속 카메라 위치이지만 분기 1회 갱신이고, 조사 시점 기준 다운로드 가능한 파일 자체가 없었다.

확실히 확보 가능한 것은 OA-22190의 이력 데이터뿐이라, 첫 결과물은 "지금 단속 중인지"가 아니라 "이 근처에 최근 단속 이력이 있는지"로 약속을 좁혀서 실제로 구현하고 검증 가능한 범위를 확보했다.

## Reconsider when

- t-data.seoul.go.kr의 실시간 API에 개인/일반 개발자로 접근할 수 있는 인증 경로가 확인될 때
- 서울시가 OA-22190 또는 동급 데이터를 표준 Open API(인증키 기반 REST 호출)로 제공하기 시작할 때

## Still-rejected alternatives

- t-data.seoul.go.kr v2x 실시간 API를 그대로 연동 — 인증 경로와 접근 허용 범위가 확인되지 않아 첫 결과물의 구현·검증을 막을 위험이 큼; 접근 경로가 확인되면 재검토.
- CCTV 위치정보(OA-20471 등)를 실시간 대용으로 사용 — 상시 카메라 위치일 뿐 실제 단속 발생 여부를 말해주지 않고, 조사 시점에 다운로드 가능한 파일도 없었음.
